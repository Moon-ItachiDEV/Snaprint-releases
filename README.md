# Snaprint — téléchargements

Les installateurs de **Snaprint**, la capture d’écran pour Windows rapide, légère et locale.

👉 **[Télécharger la dernière version](../../releases/latest)** (`Snaprint-Setup.exe`)

- L’installation se fait pour votre compte seul, sans droits d’administrateur.
- Une fois installé, Snaprint se met à jour tout seul depuis cette page.
- Chaque installateur est accompagné de sa signature (`Snaprint-Setup.exe.sig`) : Snaprint refuse toute mise à jour qui n’est pas signée par sa clé.

Ce dépôt ne contient que les versions publiées ; le code source est ailleurs.
